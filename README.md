# Gastro Cockpit AI Assistant

[Gastro Cockpit](https://gastro-cockpit.de) is staff scheduling, time tracking and payroll preparation for restaurants.
This repository holds the plugin and the directory listings that connect an AI assistant, such as Claude or ChatGPT,
to Gastro Cockpit. The MCP server itself is not part of this repository.

## Connect

Add `https://mcp.gastro-cockpit.de/mcp` as a custom connector in your AI app and sign in with your Gastro Cockpit
account. Every owner of a location can connect; a manager can connect when the owner allows it in the app.

## Privacy

The assistant sees no wages per person, no contact, tax, bank or social security data and no content of sick notes.
Details are in the [privacy policy](https://gastro-cockpit.de/datenschutz-app/), section 13.
